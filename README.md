# Задача №4: Калькулятор

Реализован интерактивный калькулятор вещественных чисел, поддерживающий:
- Основные операции: сложение, вычитание, умножение, деление, возведение в степень.
- Скобки и приоритет операций.
- Унарный минус.
- Использование предыдущего результата через символ `_`.
- Работу со специальными значениями: `inf`, `+inf`, `-inf`, `nan`.

Калькулятор корректно обрабатывает деление на ноль и операции с бесконечностями без использования `eval`.
